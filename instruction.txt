Integrate the Android app with the FastAPI backend using Retrofit and Gson.

Requirements:
- Add INTERNET permission in AndroidManifest.xml.
- Add storage permission if file download needs it on Android 10+.
- Add dependencies in app/build.gradle:
  implementation "com.squareup.retrofit2:retrofit:2.11.0"
  implementation "com.squareup.retrofit2:converter-gson:2.11.0"
  implementation "com.google.code.gson:gson:2.10.1"
  implementation "org.jetbrains.kotlinx:kotlinx-coroutines-android:1.8.1"

Backend URL:
- Use local test URL: http://192.168.42.53:8000/
- For Android emulator: http://10.0.2.2:8000/
- Later replace with hosted production backend URL when ready.

Create model classes:
- DownloadResponse with fields:
  success: Boolean
  title: String
  thumbnail: String?
  duration_sec: Int?
  selected_quality: String?
  selected_ext: String?
  download_url: String?
  audio_url: String?
  format_id: String?
  formats: List<FormatItem>
- FormatItem with fields:
  quality: String?
  ext: String?
  format_id: String?
  download_url: String?
  audio_url: String?
  type: String?

Create API interface:
- GET /api/download
- Query params: url and optional quality
- suspend fun getDownloadLink(@Query("url") url: String, @Query("quality") quality: String? = null): DownloadResponse

Create Retrofit client:
- baseUrl = "http://192.168.42.53:8000/"
- add Gson converter factory
- build Retrofit and create ApiService

Download manager:
- Use Android DownloadManager for file storage
- Save downloaded file into Environment.DIRECTORY_DOWNLOADS
- Use a safe file name from video title
- Handle MIME type based on extension
- Return downloadId for tracking

Audio-only download handling:
- If response.audio_url is not null, allow direct audio download
- Use audio URL for mp3, m4a, or webm depending on backend response
- Use proper MIME type mapping

Video-only + audio fallback:
- If response has a video stream without audio, and audio_url is available separately, use a fallback merge strategy
- Prefer FFmpeg or MediaMuxer for real MP4 muxing
- If FFmpeg is unavailable, use a simple fallback copy only as last resort

MainActivity example:
- Call RetrofitClient.api.getDownloadLink(url = "https://www.youtube.com/watch?v=dQw4w9WgXcQ", quality = "720p")
- If response.success and response.download_url != null, start direct MP4 download
- Else if response.audio_url != null, start audio-only download
- Else if video-only stream plus audio_url exists, trigger merge fallback
- Log the result and show error if no valid URL is returned

Important behavior:
- Use the backend `download_url` for direct MP4 files whenever available.
- Use `audio_url` for direct audio downloads.
- Use `formats` list to choose the desired quality.
- For local testing, run backend with:
  cd d:\fro\backend
  .\.venv\Scripts\python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
- Test API with:
  http://192.168.42.53:8000/api/download?url=https://www.youtube.com/watch?v=dQw4w9WgXcQ&quality=720p

Final goal:
- App should download MP4 directly when backend returns a full video+audio stream.
- App should download audio-only when backend returns audio-only stream.
- App should support fallback merge for video-only + audio stream combinations.
- Before production, replace the local base URL with the hosted backend URL.
